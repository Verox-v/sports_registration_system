# Sports Competition Registration System

My first Python project made while learning Python.

This console application allows users to register for sports competitions and checks whether they meet all the required conditions.

## Available sports

* Basketball
* Football
* Volleyball

## Requirements checked

Depending on the selected sport, the program checks:

* Age
* Height
* School grade

## Features

* Functions
* While loops
* Input validation
* Error handling using try/except
* Boolean logic
* User-friendly prompts
* Restart system
* Multiple sports with different requirements
